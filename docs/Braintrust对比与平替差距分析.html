一、Braintrust 全功能梳理

Braintrust 定位是「AI 开发平台 / 主动式智能体可观测」，核心理念是 evals 即产品设计，把生产 trace 自动变成测试用例，形成「生产 → 评测 → 部署」闭环。能力按五大工作流阶段 + 支撑能力组织：

① Instrument（采集）

  • 多语言 SDK：Python / TypeScript / Go / Ruby / C# / Java 等
  • 原生 OpenTelemetry 导出；适配 13+ 框架（LangChain、LangGraph、Instructor、Autogen、CrewAI、Vercel AI SDK、Cloudflare…）
  • 全链路 Trace：LLM 调用、工具调用、应用逻辑各自成 span，记录 input/output/参数/延迟/Token/成本/metadata

② Observe（观测）

  • Brainstore：专为 AI trace 设计的数据库，支持百万级 trace 全文检索、快速 span 加载
  • 实时性能监控、自定义视图、告警（Slack / Webhook）
  • Topics（自动模式发现）：每日 LLM 分类流水线，内置 facet（Task 任务 / Sentiment 情感 / Issues 问题）+ 自定义 facet；散点图聚类并按占比排序；分类写回每条 trace 供过滤
  • Loop 自然语言调查：用 NL 追问 trace、定位问题

③ Annotate（标注 / 人工评审）

  • 对 trace / 实验 span / 数据集行 打人工分；键盘快捷键标注
  • 项目级 rubric：Pass/Fail、分类字段、连续滑块（1–5）、自由文本备注
  • 生产用户反馈可直接挂到 trace；标注结果成为一等信号，用于过滤与发布闸门

④ Evaluate（评测）

  • Eval() 函数 → 命名不可变实验快照；数据集版本化 + 快照
  • 评分器分三类：Autoevals 预置库、LLM-as-a-judge、自定义代码；另有 Classifiers（分类标签）
  • Autoevals 预置库（节选）：Factuality、Faithfulness、ContextPrecision/Recall/Relevancy、AnswerCorrectness/Relevancy/Similarity、JSONDiff、ValidJSON、ExactMatch、EmbeddingSimilarity、Levenshtein、Summary、Translation、ClosedQA、Battle、Humor、Possible、Security、Sql、Moderation、NumericDiff、ListContains、LLMClassifier / OpenAIClassifier，并含 RAGAS 系
  • 评分返回 0–1 连续值（非硬 pass/fail），可设阈值；支持 Span 级 / Trace 级评分
  • 实验对比视图：两实验并排，绿升红降；metadata tag 作为过滤维度；--watch 热重跑；UI 免代码跑实验
  • 一致性：trial_count 每输入多次试验测波动（类 pass@k 思路）

⑤ Deploy（部署 / 在线评分 / 网关）

  • Online Scoring：同一套评分器异步作用于生产 trace（不增加请求延迟），采样率可调，低分触发告警
  • AI Gateway（beta 免费）：100+ 模型（OpenAI/Anthropic/Google/AWS/Mistral…）统一 OpenAI 兼容端点；响应缓存（AES-GCM，TTL≤7天，按用户隔离）；有序故障转移；项目/组织级凭证；支持 embeddings
  • Prompt / Function 管理：提示与函数是一等版本化对象（slug + version pin）；npx braintrust push/pull 双向同步；环境（dev/staging/prod）；质量闸门阻止劣质版本晋升；即时回滚；REST 调用；Zod/Pydantic 类型、流式

支撑能力

  • Loop AI Agent：用自然语言生成数据集、优化提示、构建评分器、发现生产模式
  • MCP Server：在 IDE 内查询日志、跑 eval、更新提示
  • CI/CD：braintrustdata/eval-action GitHub Action，PR 评论打分摘要、阈值阻断合并；Reporter() 自定义阻断；--first N PR 冒烟
  • 安全合规：SOC 2 Type II、GDPR、HIPAA、SSO/SAML、细粒度 RBAC、BYOC/自托管（Terraform AWS/GCP/Azure）、审计日志（企业）
  • 定价：Starter 免费（1GB/1万 scores/无限用户）、Pro $249/月、Enterprise 定制

我方相对 Braintrust 的 6 个超车点（应作为主诉卖点）：
  1. 交界层四类原子评测（契约/权限/兜底/归因）—— Braintrust 无此概念，这是「智化融合系统交付验收」差异化内核。
  2. 三方解耦（bare/harness/full 通过率 + harness_only_gain + scaffold_leakage）—— Braintrust 无法区分「壳帮了还是脚手架漏了」。
  3. 轨迹归因—— 不仅给 trace 打分，更定位失败由哪一步 span 引起。
  4. Judge 三通道隔离 + 成本闸门—— LLM 裁判成本可预算、可熔断。
  5. 版本钉 provenance—— harness/model/dataset 三重版本绑定，结果可复现。
  6. 国内合规 / 信创 / 等保 + 中文业务 Rubric 定制—— Braintrust 的 SOC2/GDPR/HIPAA 体系对国内政企不对口，这是「国内可用、优于」的战略支点。

  • N10 日志检索与数据出库 —— 全文检索 + 自定义列/保存视图 + 一键转数据集 + 对象存储导出（Hive 分区）+ 保留策略。海量 trace 可检索、可归档是「可交付」前置。
  • N11 测试框架集成与外部评测框架 loader —— pytest / Vitest / Node 插件 + lm-eval 等 loader。门禁下沉到日常；与你现有 pytest / lm-eval 工作流直接打通。
  • N12 权限组与细粒度 ACL + 服务账号 —— 项目级/资源级权限组、service account、provider 权限、只读/导出权限模型。与 O2 同批做，企业交付必需。
P2差异化补漏：实现「优于 / 更贴国内交付」
  • O10 工具注册与托管执行（Tools 一等对象）—— 函数→工具、隔离执行、可挂 prompt、可直调。支撑工具级评测（调用正确性 / 参数合法性）。
  • O11 远程 / 沙箱评测 —— 评测代码 push 一次，UI 免本地环境按需运行。多供应商拆包协作时，甲方无需装环境即可复跑。
  • O12 Patterns 式自动问题发现 —— 定时调查 → 带证据的发现 → 一键转 scorer / facet / monitor。与 O6（Topics）互补：广覆盖 + 深调查。
  • O13 Token / 成本预算体系 —— 按用户 / 密钥 / 项目维度的预算配额与超额告警。现有 Judge 成本闸门的扩展。
  • O14 CLI 补全 —— push（对象同步）/ trace（采集）/ sql（查询）子命令 + dev 模式。低成本，直接提升可用性。
P3可选增强：远期锦上添花
  • O15 Debugger / Analyze trace —— 单 trace 失败模式判定（引用证据 span）+ run 的工作分解。
  • O16 多模态附件 —— PDF / 图片进 prompt 与 playground + 渲染与筛选。
  • O17 自定义 Trace 视图 + 数据集快照 / 回滚。
两个应并入既有项的关键增强：
① N2 加「盲评」（Blind review） —— Braintrust 默认隐藏他人打分/评论/聚合，直到评审人自己打完，可选全流程隐藏以保持独立性。这一点与「第三方独立交付验收」的定位高度契合，价值高于界面本身。
② N3 加「git metadata 自动采集」 —— commit / branch / dirty / repo_info 随实验自动记录，可按 SHA 建实验；是版本钉 provenance 的补齐（我方现只有 harness/model/dataset 三钉，缺代码版本钉）。

七、结论

我方在评测正确性维度（交界层 / 三方解耦 / 轨迹归因 / 成本闸门 / 版本钉）已领先 Braintrust，且国内合规与信创是 Braintrust 的天然短板。要成为「至少不逊于且优于」的平替，关键不是照搬 Braintrust 的全部观测/网关功能，而是：先补齐评测内核的必要项（N1–N6）达到能力对等，再用品类差异点（交界层验收 + 国内合规 + 国内模型网关）实现超车。
